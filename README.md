# 🌦️ API de Consulta de Clima

API REST desenvolvida com Java e Spring Boot para consulta de
informações climáticas através de uma API externa.

## 🚀 Tecnologias

- Java
- Spring Boot
- Maven
- APIs REST

## ⚙️ Funcionalidades

- Consulta de informações climáticas
- Integração com API externa
- Exposição de endpoints REST

## 📌 Tecnologias utilizadas

Java | Spring Boot | Maven | REST API
